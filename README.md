# HealthConnect Experience Lab – Week 4

## Data Analytics Track

Week 4 focused on establishing the analytical foundation for the HealthConnect appointment project.

## Objectives

- Understand the business problem
- Review the appointment dataset and data dictionary
- Assess data quality
- Identify relevant analytical variables
- Formulate business questions
- Develop potential KPIs
- Define an initial analysis approach
- Identify assumptions, limitations, risks and dependencies

## Dataset

The project uses the supplied HealthConnect appointment dataset and accompanying data dictionary.

The dataset is fictional, synthetic and anonymised.

## Key Areas of Analysis

- Appointment attendance
- No-show patterns
- Booking lead time
- Previous no-show history
- Reminder information
- Patient and appointment characteristics
- Operational factors

## KPIs Identified

1. No-Show Rate
2. Attendance Rate
3. Reminder Coverage Rate
4. Repeat No-Show Rate
5. Average Booking Lead Time

## Deliverables

The repository contains the Week 4 initial analysis report, supporting project files and submission materials.

## Next Stage

The next stage will build on this foundation through deeper analysis and solution design.
